# קליפיק — MVP מקומי

אפליקציית דפדפן פשוטה לזרימת יצירת סרטון מוצר: מוצר → תסריט → תצוגה. כרגע יצירת הסרטון היא **הדמיה בלבד**; עדיין אין חיבור למודל AI או יצוא וידאו.

## הפעלה ב-Windows

1. התקינו Python 3.10 ומעלה, אם אין במחשב.
2. חלצו את קובץ ה-ZIP ולחצו פעמיים על `start.bat` — השרת יעלה והדפדפן ייפתח אוטומטית.
3. לעצירה: Ctrl+C בחלון השרת.

אפשר גם להפעיל ידנית מתוך התיקייה עם `python server.py` ואז לפתוח http://127.0.0.1:8765.

אין צורך להתקין חבילות צד שלישי. טיוטות נשמרות בקובץ `projects.json` בתיקייה.

## מה עובד

- ממשק בעברית ובכיווניות RTL, מותאם למובייל.
- אפשרויות שפה: עברית, English, العربية ורוסית (Русский).
- רקע ירקרק עדין וכפתורי המשך בצבע ליים.
- הוספת מוצר באמצעות קישור או עד 3 תמונות JPG/PNG של אותו מוצר; התמונות משמשות לתצוגה מקומית בלבד.
- בחירת משך סרטון: 10, 15, 20, 25 או 30 שניות.
- פתיחים כאקורדיון: הכרטיסים סגורים בתחילה; לכל אחד דוגמה, פירוט מה יופיע בסרטון ותיבת טקסט עצמאית, כולל אפשרות „פתיח משלי” למי שההצעות לא מתאימות לו.
- חמשת סגנונות הצילום נפתחים להסבר משלהם; בחירה בין דמות AI מדברת לקריינות על צילומי מוצר.
- הפתיח מוגדר כדיבור בקול עם כתוביות תואמות.
- שמירת טיוטות לשרת המקומי ופתיחת רשימת הטיוטות.
- בדיקת בריאות: `GET /api/health`.

## מה עדיין לא מחובר

- יצירת תסריטים באמצעות מודל AI.
- משיכת פרטי מוצר אמיתיים מ-Shopify.
- יצירת/עריכת קובץ וידאו, דמויות, קריינות ומוזיקה.
- משתמשים, התחברות, פריסה לענן ואחסון מאובטח.

לא הוגדרו מפתחות API ולא נעשה שימוש בשירות בתשלום. לפני חיבור מנוע וידאו יש לבחור ספק ולבדוק את המחיר לכל יצירה.
